Findings

Audited the live app (Home, Story map, Level 1, Advanced, Playground) at 1280×800 with a script that measured every visible text node's contrast against its real background and every control's hit size, plus a read of theme.css, app.css and the screens. The base is solid: every control has an accessible name, decorative emoji are already aria-hidden, dialogs are labelled and modal, and pieces can be placed by keyboard tap instead of drag. The gaps are colour pairs, a few small sizes, and no dark theme.

Build plan

How these drafts would land in the app, in order. Nothing in src/ has been changed yet.

  1. Tokens. Add the new -text, -fill, on-*, --border-control, --ring, --region, --window, --orb and --shadow-rgb tokens to theme.css. Light values go on :root; dark values under :root[data-theme='dark'] and under @media (prefers-color-scheme: dark) { :root:not([data-theme='light']) }. Set color-scheme on each.
  2. Sweep app.css. Replace the 18 #fff with --on-coral/--cloud/--field, the 19 rgba(38,48,67,…) with --shadow-rgb, and every component that sets color: var(--coral|flow|ok|bad|warn|plum) with the matching -text token. Fix .btn-primary:hover.
  3. Sizes. Apply the 12px floor and the type scale; set .btn-sm, .icon-btn, .panel-toggle and .react-flow__controls-button to 44px; wrap the teacher-mode checkbox in a 44px label row.
  4. Focus and motion. Remove the three outline: none input overrides; add the global reduced-motion rule.
  5. Theme switch. Store theme: 'system' | 'light' | 'dark' in the zustand store (persisted with the profile), write it to document.documentElement.dataset.theme, and set it before first paint with a tiny inline script in index.html so dark users don't see a light flash. Add the Theme button + menu to Chrome.tsx and the phone menu in PhoneChrome.tsx. Two theme-color metas with media.
  6. Canvas and art. Pass colorMode to <ReactFlow>; move Sparky's fixed hex to the --sparky-* constants; swap Scenery's sun for --orb and windows for --window; draw the three mono icons (users, phone, aws-cloud) as an --ink mask. Saved plan pictures in PlanExport.tsx use the theme in use, so they look like what the team sees (forcing light would flash the screen during capture).
  7. Icons. Add a small SVG icon component and replace emoji in buttons, chips and the inspector (Playground.tsx:360, :373).
  8. Check. Rerun the contrast/target script on every screen in both themes, open each overlay in dark (story card, win card, phone sheets, dialogs, menus) per the z-index lesson, and add a /styleguide theme toggle so both themes can be eyeballed together.
