Spark dark mode options Today’s dark theme and four alternatives. Every one passes WCAG AA text contrast; they differ in how clearly the layers stand apart.

Each option shows the title screen, a level and the story-map panel. The table under each name measures contrast between neighbouring layers: higher numbers mean cards, zones and panels separate more clearly. Today’s cards sit 1.17:1 from the page and have no visible edge (1.00:1), which is why the dark theme reads flat. Light mode stays exactly as it is in every option.
